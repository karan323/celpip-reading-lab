# CELPIP Reading Lab

Practice for the CELPIP-General Reading test.

- 100 tests in the real exam format: 25 each for Part 1 (Correspondence), Part 2 (Diagram), Part 3 (Information) and Part 4 (Viewpoints)
- Three levels in each part: Hard (CLB 10–11), Moderate (real exam, CLB 8–9), Easy (CLB 6–7)
- 25 full mock exams (38 questions) with real time limits and an approximate CLB score
- Review after every test: your answer, the correct answer, the reason, and the proof highlighted in the passage
- Works offline once opened. Progress is saved in the browser on each device.

## Install on iPhone or iPad
Open the site in Safari → Share → **Add to Home Screen**.

## Install on Android or desktop Chrome
Open the site → menu → **Install app** (or **Add to Home screen**).

All passages and questions are original practice material written for this app. They are not official CELPIP content.
